Import calendars (.ics)

Bring in your Outlook or Gmail calendars:

  • Google / Gmail: calendar.google.com → Settings → Import & export → Export (unzip, one .ics per calendar).
  • Outlook.com: Settings → Calendar → Shared calendars → Publish a calendar → open the ICS link and save the file.
  • Outlook desktop: File → Save Calendar → choose “Whole calendar”.

Importing the same file again updates events instead of duplicating them.

Mouse

  • Click an event to see its details, map and directions. Right-click (or double-click) it to edit. In the details card: E edit, Del delete.
  • Day/week views: drag on empty space to create, drag an event to move it, drag its bottom edge to resize.
  • Month view: double-click a day to create, drag events between days.
  • Click a date number to open that day.
